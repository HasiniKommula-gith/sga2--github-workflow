1. git init -b main
   Initializes a new local Git repository and sets the default branch name to 'main'.

2. git add <file>
   Stages changes in the working directory so they are ready for the next commit.

3. git commit -m "<message>"
   Records staged snapshots permanently into the repository's version history.

4. git checkout -b feature
   Creates a new branch named 'feature' and switches the working directory to it.

5. git checkout main
   Switches the active working branch back to 'main'.

6. git merge feature
   Integrates commit history and file changes from the 'feature' branch into 'main'.

7. git log --oneline --graph --all
   Displays a compact visual commit history across all branches.

8. git status
   Shows the state of the working directory and staging area, confirming ignored files.

9. git revert HEAD --no-edit
   Safely undoes the changes introduced by the latest commit by creating a new inverse commit.

10. git remote add origin <url>
    Links the local Git repository to a remote repository hosted on GitHub.

11. git push -u origin main
    Uploads local commits on the 'main' branch to the remote GitHub repository.
